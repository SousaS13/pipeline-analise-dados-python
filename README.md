# Pipeline de Extração, Tratamento e Análise de Dados (Python & SQL)

Este projeto apresenta o desenvolvimento de um pipeline automatizado para manipulação, limpeza e análise exploratória de grandes volumes de dados institucionais, simulando cenários reais de Governança de Dados e Business Intelligence (BI) no setor público.

---

##  Tecnologias e Ferramentas Utilizadas

* **Linguagem de Programação:** Python (foco em engenharia e análise de dados).
* **Bibliotecas Principais:** Pandas (para manipulação, engenharia de atributos e tratamento de inconsistências).
* **Banco de Dados:** SQL estruturado para cruzamento e consolidação de registros.
* **Controle de Versão:** Git e GitHub.

---

##  Etapas do Projeto e Funcionalidades

O pipeline foi estruturado para garantir a qualidade da informação através de processos rigorosos de ETL (Extract, Transform, Load):

### 1. Tratamento e Higienização de Dados (Python/Pandas)
* **Consistência de Dados:** Identificação e tratamento rigoroso de valores nulos, duplicados ou corrompidos, garantindo que apenas dados válidos sigam para a análise.
* **Manipulação Estruturada:** Filtros avançados e transformação de tipos de dados para otimização de performance.

### 2. Consultas Avançadas e Extração (SQL)
* **queries Estruturadas:** Escrita de comandos complexos utilizando `JOINs`, funções de agregação (`SUM`, `COUNT`, `AVG`) e `subqueries` para relacionar bases de dados distintas.
* **Geração de Relatórios:** Extração de métricas gerenciais prontas para subsidiar tomadas de decisão.
